## Projetos em destaque

### [Carteira API](https://github.com/Blima-P/carteira-api)
API REST de carteira digital com cadastro, login JWT, depósitos,
transferências entre usuários e consulta de saldo.
Transações ACID, idempotência, arquitetura modular com Spring Modulith,
migrações com Flyway e CI no GitHub Actions.
Java 21, Spring Boot e PostgreSQL.
Extrato paginado está no roadmap; ainda não há endpoint de extrato.

### [ERP Acadêmico](https://github.com/Blima-P/ERP-Academico)
Projeto acadêmico desenvolvido em equipe com React e Firebase.
Gestão de alunos, cursos e matrículas, com autenticação,
relatórios e exportação CSV.

### [Análise de Acidentes da PRF](https://github.com/Blima-P/Projeto_AcidentesPRF)
Projeto acadêmico em equipe para explorar relações entre condições
meteorológicas e gravidade dos acidentes registrados pela PRF.
Utiliza Python, pandas e Streamlit para análise e visualização dos dados.

### [InvestStart](https://github.com/Blima-P/InvestStart)
Aplicação web educativa para quem nunca investiu. Coleta dados
atualizados de ações, FIIs, Tesouro Direto, ETFs e criptomoedas
e sugere uma carteira diversificada conforme o perfil do investidor,
explicando cada escolha em linguagem simples.
Python, FastAPI e React com TypeScript.
Em desenvolvimento: backend estruturado com testes e lint;
próximas etapas são o frontend e a coleta de dados de mercado.
